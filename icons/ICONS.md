# ss13-system - Icon Guide

## Current Icons
Using Foundry VTT default system icons:
- `icons/weapons/` - Weapons (guns, melee)
- `icons/equipment/` - Armor, uniforms, gear
- `icons/tools/` - Tools, medical items
- `icons/items/` - General items

## Custom Icons
Place custom PNG files in `icons/items/` and reference as `icons/items/filename.png`

## BandaStation Compatibility
BandaStation icons are .dmi format (BYOND). To convert:
1. Use `dmiparse` or online converters
2. Or download from: https://wiki.ss13.co/Category:Icons

## Slot Icons
Found in `icons/slots/` - copied from BandaStation UI:
- `uniform.png`, `armor.png`, `head.png`, `belt.png`
- `back.png`, `id.png`, `shoes.png`, `hand_l.png`, `hand_r.png`
